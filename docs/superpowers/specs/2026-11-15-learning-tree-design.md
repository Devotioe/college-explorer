# 混合式課程學習樹設計

## 目的

把目前平行排列的課程地圖改為有先後順序、可分支的樹狀學習路徑，讓學生看得出「已經修過什麼、下一步先修什麼、最後能前往哪些進階課程」。

## 目標與非目標

- 目標：由左到右顯示 `OCR 已修課 → 基礎／補強 → 進階課 → 目標能力`，同一階段允許分支與匯流。
- 目標：灰色代表 OCR 已修課、政大藍色、清大紫色，保留目前的兩校辨識方式。
- 目標：每條關係顯示「官方先修」或「建議銜接」，避免把推估關係冒充校方規定。
- 非目標：這次不建立完整的全校課程知識圖譜，也不聲稱語意推估等同正式擋修規定。
- 反目標：不再使用三欄排排站，也不把所有推薦課塞在同一層。

## 資料與排序規則

1. 優先解析課程資料中的 `prerequisites`，以課號或課名配對現有課程，建立官方先修邊。
2. 官方資料缺漏時，才依課程層級、名稱中的一／二或基礎／進階、共同主題、課程簡介與學習目標推估銜接順序。
3. OCR 課程若能配對課程庫，作為已完成的根節點；無法配對時仍顯示灰色節點，但不虛構官方關係。
4. 圖上限制為少量關鍵節點，優先顯示能通往目前目標的最短、最有解釋力路徑。
5. 日後補入官方資料時，同一對課程的官方關係會覆蓋語意推估關係。

## 介面

- 桌面版採左到右的 SVG 曲線樹：已修課在左、目標能力在右，中間依深度分層。
- 節點可點擊並切換目前目標；線條旁或節點內顯示關係來源。
- 官方先修使用實線，語意建議使用虛線。
- 手機版改為由上到下的階段式樹，保留分支縮排與來源標籤，不強行壓縮桌面圖。
- 下方仍只保留儲存、歷史紀錄與目標說明，不重複另一張圖。

## 方案比較與決定

- 純官方資料：可信度最高，但目前缺漏會讓地圖過於稀疏。
- 純語意推估：覆蓋率高，但容易被誤認為正式先修規定。
- 混合模式：官方優先、推估補缺，兼顧可信度與完整度。

決定採用混合模式；使用者之後可補官方缺漏資料。

## 驗收重點

- 視覺上必須明顯是有深度與分支的樹，而非平行清單。
- 至少能分辨已修、政大、清大與目前目標。
- 官方與推估關係在視覺和文字上都能區分。
- 無官方資料時不得顯示成「官方先修」。
- 桌面與手機皆可閱讀，且探索頁搜尋框行為不受影響。
